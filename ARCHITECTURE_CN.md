## 🔑 关键点说明

### 1. **ESP32 设备端（不需要改动）**

**已有功能（固件已实现）：**
- ✅ 音频采集和播放
- ✅ Opus 编解码
- ✅ WebSocket 客户端
- ✅ 协议解析
- ✅ 状态管理
- ✅ 唤醒词检测

**您需要做的：**
- ❌ **不需要安装 Python**
- ❌ **不需要安装依赖**
- ✅ **只需要配置服务器地址**

```bash
# 唯一需要做的：修改 NVS 配置
configure_device.bat COM3 ws://192.168.1.100:8765
```

### 2. **Python 服务器端（需要搭建）**

**运行位置：**
- Windows PC（您的开发电脑）
- Linux 服务器
- 云服务器（阿里云/腾讯云）

**需要安装的依赖：**

```bash
# 核心依赖
pip install websockets      # WebSocket 服务器
pip install dashscope       # 百炼 SDK
pip install opuslib         # Opus 编解码
pip install edge-tts        # TTS 语音合成
pip install pydub           # 音频处理

# 系统依赖
# Windows: 安装 FFmpeg
# Linux: sudo apt install ffmpeg libopus0
```

**代码文件：**
- `xiaozhi_full_server.py` - 完整服务器（包含 TTS）
- `simple_bailian_test.py` - 简化版（只测试百炼对话）

### 3. **数据流向**

```
语音输入:
用户 → 麦克风 → ESP32 → WebSocket → Python → ASR → 文本

对话处理:
文本 → 百炼应用 → 回复文本

语音输出:
回复文本 → TTS → Python → WebSocket → ESP32 → 扬声器 → 用户
```

## 📝 您的问题答案总结

### Q1: 参数输入是根据语音转文字的吗？

**是的！**

```python
# 流程：
用户语音 → ASR 识别 → "你好小智" → 这个文本就是百炼应用的输入

response = Application.call(
    prompt='你好小智'  # ← ASR 识别的文本
)
```

### Q2: 模型返回的数据如何转语音播放？

**是的！**

```python
# 流程：
百炼回复文本 → TTS 合成 → Opus 音频 → 发送给设备 → 扬声器播放

reply = "你好！我是小智"
audio = await tts.synthesize(reply)  # 文字转语音
await websocket.send(audio)          # 发送给设备
# 设备自动播放
```
